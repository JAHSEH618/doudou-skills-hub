# Ilya 的 30 篇论文清单，被做成了 30 天的课

Ilya Sutskever 留过一份 30 篇的 AI 论文清单，附了一句「真读懂了这些，就懂了当下 AI 90% 的要点」，这句话被写在了 30u30 仓库 README 的开头。存下这份清单的人不少，卡住的地方也集中：打开第一篇，满屏公式就读不下去了。

[GitHubDaily](https://x.com/GitHub_Daily) 10 月 21 日 9:00（JST）[发帖介绍](https://x.com/GitHub_Daily/status/2112695371118080053)了把这份清单课程化的开源项目 [30u30](https://github.com/Ojhaharsh/30u30)。仓库 2026 年 1 月创建，查询时 1153 Star，[课程站点](https://ojhaharsh.github.io/30u30/) 已上线。这篇按原帖和仓库 README 整理，值得记录的原因：排序就是一部深度学习简史，且每篇都有从零代码，可以直接当自学路径用。课程代码没有逐日跑过，下文都标清了证据范围。

## 30 天怎么排

README 把 30 篇论文按历史脉络排成六个单元，一天一篇：

- 第 1–7 天 The Foundations：RNN、LSTM、RNN 正则化，加最小描述长度（MDL）两篇和两篇复杂系统方向（Complexodynamics、Coffee Automaton）。
- 第 8–12 天 Deep Learning Explosion：AlexNet、ResNet、ResNet v2、空洞卷积、Dropout。
- 第 13–16 天 The Transformer Era：Attention Is All You Need、The Annotated Transformer、Bahdanau 注意力、Order Matters（指针网络的前身）。
- 第 17–22 天 Specialized Architectures：Neural Turing Machines、Pointer Networks、关系推理两篇（Relational Reasoning、R2L）、Neural Message Passing、Deep Speech 2。
- 第 23–28 天 Generative Models & Scaling：VQ-VAE、GPipe、Scaling Laws、Kolmogorov 复杂度、Legg 的 Machine Super Intelligence、CS231n 课程笔记。
- 第 29–30 天 Deep RL & Alignment：PPO、RLHF，结尾落在 ChatGPT 背后的对齐流程。

从循环网络到视觉爆发，再到注意力、专用架构、生成与扩展、最后 RLHF，这条线就是深度学习发展的时间轴。

## 每天的结构

原帖的介绍是：每篇配一份大白话讲解，加一页「讲给 5 岁小孩听」的速览，然后从零把代码写一遍，配图看着学；每天 5 道练习题，答案附上，代码在普通电脑的 CPU 上跑，几分钟出结果。这些表述来自原帖，我没有逐日验证。

仓库自己的定位是「Rustlings，but for deep learning fundamentals」：读论文、看懂数学、自己把它写出来。要求 Python 3.8+。

## 评论区补的两个视角

原帖下的回复点到了这门课的成色问题，以下按原话转述（评论区观点，未独立核验）：

- NextSignal（@Grok9527）：30 篇拆成 30 天的切法是对的，很多人卡住是因为没有顺序和节奏；被忽略的是读完之后的落地，比如用小项目把 Transformer 和 RAG 串起来验证。
- 赛博隐者（@HSkyer99871）：这份清单最值钱的是顺序，按历史脉络排下来就是一部深度学习简史；课程化的难点在每篇的「为什么这篇是关键」，缺了这层讲解，30 天计划很容易变成高级版待办清单。
- 邓红宇（@cug_denghy）：要学习的内容太多，用来学习的时间太少，怎么破。
- 彭敬寅（@Levi_J_Peng）：清单存过，真打开第一篇公式就关了；对他来说，一周把 agent 账单拆一遍，比把 RLHF 论文啃完更有用。
