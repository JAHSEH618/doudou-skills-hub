# 格式与 x-accounts.txt 同款：
#   `## 组名 !` 起一组；组名末尾 `!` = 必看组（每期必查，1 天窗口也不例外，
#   窗口内新条目必须按硬规则 10 读原文入报告；无 `!` = 被动组（照常抓，挑相关的不相关就丢）
#   组内每行一个信源：`<feed URL 或 page 标记>  # 注释`
#   `page:` 前缀 = 非 RSS 页面，脚本里有对应专用解析器（目前只有 anthropic-engineering）
#
# 维护：feed 失效（404 / 停更超 3 个月）直接删行；新源先 curl 验证有货再加。
